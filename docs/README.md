# highrisebot

> High-performance, concurrency-safe, unofficial Highrise Virtual World Bot & Web API SDK written in **Golang**.

[![Go Reference](https://pkg.go.dev/badge/github.com/rezadesky/highrisebot.svg)](https://pkg.go.dev/github.com/rezadesky/highrisebot)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

---

## ⚡ Highlights
- **Full Highrise Protocol Support**: Chat, whisper, teleport, walk, emote, react, kick, ban, unban, tip, wallet, inventory, outfit, and voice chat.
- **Auto Reconnect & Resilience**: Automatic keepalive heartbeat with exponential backoff and randomized jitter.
- **Built-in Command Framework**: Prefix routing (`!ping`), command aliases, cooldowns, owner guards, and auto-generated help.
- **Multibot Architecture**: Run and supervise hundreds of isolated bots simultaneously in a single process.
- **Production Ready**: Native context cancellation, graceful shutdown, bounded queues, and zero panic guarantees.
